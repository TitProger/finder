# Экраны Finder

Общая папка макетов страниц. Первая страница поиска остаётся на уровень выше: `../screen.png` и `../code.html`. Новые экраны лежат здесь. В каждой папке `screen.png` — вид, `code.html` — выгрузка для адаптации, `original.zip` — архив как скачан, без перепаковки.

`stitch_finder (1).zip` и `stitch_finder (2).zip` — один и тот же экран входа. Сохранён один раз в `vhod/`.

| Папка | Окно | Откуда |
| --- | --- | --- |
| `istoriya-poiska` | История товаров, которые клиент уже искал | `stitch_finder.zip` |
| `kartochka-tovara` | Открытая карточка одного товара: описание, характеристики, цены, логистика | `stitch_finder (3).zip` |
| `vhod` | Вход через VK, Telegram, Яндекс или Google | `stitch_finder (1).zip` |
| `profil` | Карточка профиля: баланс, тема, язык | `stitch_finder (4).zip`, кадр finder_1 |
| `popolnenie` | Окно тарифов и пополнения | `stitch_finder (4).zip`, кадр finder_2 |

Цифры, имена фабрик и фото в макетах — демо. Это не ответ сервера и не разрешение выдумывать ставки.
